# Handoff — 2026-06-22

## What was changed this session

### host/config.py
- `ROBOT_LENGTH_MM` corrected **370 → 320 mm** (measured: 110 mm rear-to-ArUco + 210 mm ArUco-to-nose)
- `ARUCO_FROM_BACK_FRAC` corrected **0.33 → 0.344** (110 / 320)
- `BALL_GATE_THRESHOLD_PX` reduced **80 → 50 px**
  - 80 px was causing the gate to fire at the robot's starting position when it happened to be within 80 px of a nearby ball (seen: robot started 66 px from ball (303,400), gate fired immediately at wp 1/27 and counted a false "collected").
  - 50 px still exceeds the trim distance (135 mm = 47 px at school px_per_mm ≈ 0.349), so the gate still fires correctly at the trimmed endpoint.

### host/pathfinding.py
- Ball pickup trim changed to **`TRIM_MM = 135.0`** (was using `robot_half_length_mm = 185 mm`).
  - Geometry: ArUco-to-nose = 210 mm. Trim 135 mm → nose at ball + (210−135) = **75 mm past ball**. This puts the ball mid-way inside the 90 mm gate arm reach.
  - Previous trim values tried and their outcomes:
    | Trim | Nose overshoot | Result |
    |---|---|---|
    | 248 mm | −38 mm (short of ball) | Robot stopped too far away |
    | 185 mm | +25 mm past ball | Close but not collecting |
    | 150 mm | +60 mm past ball | Closest yet, still not collecting |
    | 135 mm | +75 mm past ball | **Current — not yet confirmed** |
  - Note: previous trim iterations were confounded by a wrong `ARUCO_FROM_BACK_FRAC` (0.33 gave ArUco-to-nose = 248 mm instead of the measured 210 mm), which has now been corrected.

### host/loop.py
- Added `--no-restart` CLI flag. When passed alongside `--profile` or `--tcp`, skips the SSH restart sequence and connects directly to an already-running EV3 server. Useful when the robot is already up and only the host loop needs restarting.

## How to start the robot (school network)

The `--profile school` flag no longer auto-restarts. Use this sequence:

```bash
# 1. SSH restart — kills stale processes, starts ev3_server + main.py
ssh robot@10.56.138.36 'bash /home/robot/CDIO-Mindstorms/robot/restart.sh'

# 2. Wait ~8 s, then confirm main.py is ready
ssh robot@10.56.138.36 'cat /tmp/main.log | tail -5'
# Should show: [EV3] Follow loop ready

# 3. Start host loop (skip SSH restart since we just did it manually)
cd host
python3.11 -u loop.py --profile school --no-restart
```

If only the host loop died (EV3 still running):
```bash
python3.11 -u loop.py --profile school --no-restart
```
